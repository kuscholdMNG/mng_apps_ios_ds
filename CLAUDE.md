## Scope

This library holds only what iOS can't share with Core. Default every item to Core. An item comes here only after Karl approves it as **iOS only** on the Core file's ownership pages (see `mng_apps_core_ds/docs/PLATFORM-OWNERSHIP.md`).

Typical iOS-only items: SF Symbols glyphs, Sign in with Apple, native eNewspaper viewer controls, player skip controls, the section header band (`header`), and any iOS-only exceptions to Core values.

## Tokens (generated, DEC-04)

`Tokens/MNGBrandColors.swift` is generated by Style Dictionary from the Core repo's `tokens/` (DTCG). **Never edit it here**: change the Core data, then run `npm run tokens && npm run build` in `mng_apps_core_ds`. Usage: `MNGBrandPalettes.tdp.navbar` (UIKit) or `palette.color(\.navbar)` (SwiftUI); `MNGBrandPalettes.forMarket("TDP")`. Every color is written from its exact hex bytes; hex and RGB for each market are in Core `docs/BRAND-COLORS.md`.
